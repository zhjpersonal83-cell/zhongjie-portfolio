Marginloom - AI reliability workbench

An AI-assisted software prototype connecting prediction evaluation, calibration, selective prediction, human review and reproducible evidence reports.

← All projectsLaunch application ↗View source on GitHub

The question

How can an evaluation workflow show which predictions to accept, which to review and what evidence supports the policy? Marginloom connects model outputs to inspectable metrics, review decisions and saved reports.

Implemented workflow

The repository implements temperature scaling, risk-coverage and threshold exploration, validated JSON prediction imports, saved run and policy snapshots, local ensemble inference, persisted review notes and JSON evidence exports. A separate companion experiment demonstrates segmentation on synthetic images.

Engineering approach

A React and TypeScript interface connects to typed API handlers and SQLite/D1 persistence. Python and scikit-learn produce reproducible baseline models and evaluation exports. Workspace boundaries, validation and audit records support the demonstration workflow.

Evidence and scope

The public MIT-licensed repository includes source, model and prediction exports, documentation and tests. Its web, research and container GitHub Actions jobs passed on 4 October 2026 for the recorded verification commit. This portfolio update inspected those records; it did not rerun the complete prototype.
