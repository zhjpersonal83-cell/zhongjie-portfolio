Completed BSc project · Computer vision

Emotion recognition using visual information

A complete image-to-prediction workflow, linking a Swin Transformer model with a responsive Java/Tomcat web application.

← All projects

The problem

Build an experimental application in which a user submits a facial image, the system validates and preprocesses it, a model estimates an expression category, and a clear interface returns the result.

My contribution

Literature review, requirements analysis, architecture, front-end and server-side implementation, model integration, testing, results analysis and the final technical report.

Implementation

The supplied report describes a Java/Tomcat application connected to a Python/PyTorch pipeline using a pretrained Swin Transformer. It discusses FER2013, RAF-DB and synthetic augmentation sources.

Reported result

The final report records 76.25% accuracy on its mixed test set. FER2013, RAF-DB and generated-image tests are separate experimental settings with different results; the mixed figure must not be relabelled as a single-dataset score. These are report-derived results, not independently reproduced measurements or estimates of a person’s internal emotional state.

Outputs & learning

  • A working academic workflow covering interface, application logic and model inference.
  • Requirements, architecture, error handling and responsive interface documentation.
  • Model evaluation with confusion matrices and class-level discussion.

Scope & limitations

  • Facial-expression labels are not direct measurements of internal emotion.
  • Dataset differences in pose, lighting, demographics and annotation affect generalisation.
  • The project is an academic demonstration; additional consent, validation and data controls would be needed for other settings.

Evidence basis

Supplied 2025 BSc final report.
