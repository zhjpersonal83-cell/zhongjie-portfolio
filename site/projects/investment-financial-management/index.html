IAFM - Investment & financial management

A Java MVC application for multi-currency financial reports, paired account transfers and administrator-managed inflation records.

← All projectsLaunch application ↗View source on GitHub

Domain and workflows

Accounts, transactions and positions feed a shared reporting workflow. Internal transfers use paired journal entries and are listed separately from income and expenses; ordinary transactions retain their original currency and account.

Application engineering

The existing Java MVC structure separates request handling, domain logic and persistence. Server-side account permissions control inflation maintenance, while transfer entries are written and reversed together in database transactions.

Interface design

Reports can switch between ten major currencies using the cached daily exchange-rate snapshot. Inflation and cash-flow tables support filtering and reversible column sorting, with monthly inflation readings recorded on the 15th.

Evidence available

The deployed application is available from the launch link. Sign in with an existing account to access personal financial records. The case study documents its architecture and workflows without publishing private accounts or operational data.
