OutcomeLab — Interactive AI reliability lab

An interactive AI reliability lab where visitors challenge a classifier, teach corrections, and compare real learning on clean and shifted synthetic data.

← All projectsLaunch application ↗View source on GitHub

Break it. Teach it. Measure it.

Try a synthetic support ticket, correct its category, then inspect measured changes in accuracy, confidence, calibration and the confusion matrix. Corrections update a real online classifier in an isolated session; reset and rollback make experiments reversible.

Reproducible engineering

A React and TypeScript interface connects to FastAPI and scikit-learn. Fixed data partitions, controlled drift experiments and JSON/CSV exports support inspection. Automated checks cover backend behaviour, browser workflows and Docker startup.
