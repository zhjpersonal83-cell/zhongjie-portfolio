OutcomeLab：交互式 AI 可靠性实验室

基于 Java Web 的交互式 AI 可靠性实验室：挑战分类器、执行真实在线纠正，并在独立会话中比较原始与偏移数据评估，支持回滚及 JSON/CSV 导出。

← 全部项目进入应用 ↗在 GitHub 查看源码

挑战、纠正、衡量。

输入合成客服工单并纠正分类，查看准确率、置信度、校准指标与混淆矩阵的实际变化。每次纠正都会更新会话内独立的在线分类器，并支持重置与回滚。

可复现的工程实现

Java 21 Servlet 控制器与原生 HTML/CSS/JavaScript 界面打包为 Maven WAR，部署于 Tomcat 9。JDBC/MySQL 提供不可变且经过校验的基线模型；纠正记录和模型快照仍仅保存在临时内存中。测试对照原实现的预测与学习更新，并检查隔离、导出和精确回滚。
