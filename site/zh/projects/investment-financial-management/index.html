IAFM：投资与财务管理

以 Java 实现的应用，涉及结构化财务记录、校验、持久化存储与清晰的报告界面。

← 全部项目进入应用 ↗

领域与流程

围绕账户、交易、持仓及面向用户的汇总组织实体和流程。公开案例聚焦如何将复杂领域划分为可管理的应用职责。

应用工程

采用分层 Java 设计，涉及持久化、输入校验、访问控制及错误处理，将领域逻辑与界面展示分离。

界面设计

通过信息层级、可筛选的数据视图及明确的空状态和错误状态，帮助用户理解结构化记录。

已有证据

可通过入口访问已部署的应用，并使用已有账户登录查看个人财务记录。本案例介绍架构与工作流程，不公开私人账户或运行数据。
