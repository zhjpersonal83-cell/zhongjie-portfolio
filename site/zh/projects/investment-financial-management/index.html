投资与财务管理应用。

一个私人 Java 应用，也是本作品集设计风格的参考。公开内容仅限架构和工程决策；源代码、凭据和私人运行数据不会分发。

领域建模

为账户、交易、持仓、报告和用户摘要设计结构化实体与工作流。

应用工程

分层 Java 设计、持久化、验证、访问控制、异常处理和关注点分离。

仪表盘 UX

面向复杂财务信息的信息层级、可筛选数据视图、响应式布局和清晰状态。

公开证据

可以安全说明的内容。

需求与工作流

展示了如何把多步骤领域问题转化为界面、验证规则和持久化数据结构。

秘密不应进入前端或 Git 历史；数据库用户应遵循最小权限；公网部署必须分离源码、运行配置和生成产物。
