IAFM：投资与财务管理

采用 Java MVC 的财务应用，支持多币种报告、账户转账配对分录，以及由管理员维护的通胀记录。

← 全部项目进入应用 ↗在 GitHub 查看源码

领域与流程

账户、交易与持仓共同支撑报告流程。内部转账使用成对记账分录，单独列出并排除在收入与支出之外；普通流水保留原币种和所属账户。

应用工程

沿用现有 Java MVC 架构，将请求处理、领域逻辑与持久化分离。通胀维护权限由服务端账户身份决定，转账分录通过数据库事务成对写入与撤销。

界面设计

报告可使用缓存的每日汇率快照，在十种主要货币之间切换。通胀与收支列表提供筛选和表头双向排序，每月通胀记录日期统一为15日。

已有证据

可通过入口访问已部署的应用，并使用已有账户登录查看个人财务记录。本案例介绍架构与工作流程，不公开私人账户或运行数据。
