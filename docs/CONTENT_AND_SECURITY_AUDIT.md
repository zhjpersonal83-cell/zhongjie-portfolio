# Content and security audit

- Pure HTML/CSS/JS public build.
- Original BSc certificate intentionally included at the user's request.
- Results summary is excluded.
- Private emails, date of birth and registration number are excluded.
- MSc dissertation material is excluded.
- Full BSc report is excluded; only a public case study is derived from it.
- No source maps, JSP, Java classes, databases, credentials or private repositories.
- External links use `noopener noreferrer`.
- Core content is present in HTML and remains readable without JavaScript.
- Motion enhancements respect `prefers-reduced-motion`.
